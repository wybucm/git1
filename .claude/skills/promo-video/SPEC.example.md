# SPEC：看板宣传片（范例）

> 这是 `trello/index.html` 那支 58 秒宣传片的 SPEC，成片源码在仓库 `video/`（`director.html`、`audio.py`）。
> 新项目复制 `SPEC.template.md` 到仓库根目录 `SPEC.md`，照这份的粒度填写。

## 1. 规格

| 项 | 值 |
| --- | --- |
| 分辨率 / 帧率 | 1920×1080，30 fps（导演页 `FPS = 30`） |
| 时长 | ≤ 60 s，本片 `DURATION = 58` |

## 5. 风险点与冒烟测试计划

| 风险 | 冒烟测试（`--scale 0.25`，2–3 s） | 通过标准 |
| --- | --- | --- |
| 看板拖拽是否接受合成 Pointer 事件 | 最小剧本：按下第一张卡 → 拖到第二列 → 松手 | cues 里依次出现 `grab`、`lift`、`flip`、`dropStart`、`drop` |
| 合成器动画跟不上虚拟时间（落位瞬间结束） | 同上，松手时 rate=0.25 | `(drop − dropStart) × r ≈ 0.2 s`（过渡时长），而不是 ≈ 1 帧 |
| 慢镜头是否真实慢放 | 同上，比较 rate=1 与 0.25 时的 `drop − dropStart` | 后者约为前者 4 倍 |
| 字体未加载 / 方块字 | `--stills` 截标题帧 | 中文为 Noto Sans SC，无方块 |
| 开场终端被 3D 裁切 | still 截 3.9 s | 终端完整 |
| 大标题挡住卡片 | still 截 11.8、14.2、16.8 s | 标题在左侧，卡片完整可见 |
| 音频长度与视频一致 | 冒烟产物混流 | 两条流时长差 < 0.1 s |
